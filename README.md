# Memory Mate

Memory Mate is a mobile application designed to support Alzheimer’s patients and elderly users in their daily lives by helping them remember important tasks, medications, appointments, and personal information through a simple and user-friendly experience.

## 📱 Project Overview

The application was developed as a Graduation Project in 2024 with the goal of creating an accessible and supportive solution for people suffering from memory loss and cognitive decline.

Memory Mate focuses on:
- Daily reminders
- Medication notifications
- Emergency contact access
- Easy-to-use interface for elderly users
- Simple navigation and clean UI
- Personalized memory assistance features

## ✨ Features

- User authentication
- Reminder scheduling
- Medication tracking
- Notifications and alerts
- Simple and accessible UI
- Persistent local data storage

---

## 🧠 Purpose

The purpose of this project is to provide a practical and user-friendly assistant for Alzheimer’s patients while also helping caregivers monitor and support their daily routines more effectively.
